# 强度剖面沿路径的内置比例

Type: grilling
Status: resolved
Blocked by: 01, 06

## Question

命令不暴露风眼宽度/剖面形状时，内置强度剖面沿路径如何切分：升段、峰值平台、风眼、另一侧峰值、降段各占路径水平长度的多少？风眼宽度默认多少（格或路径比例）？峰值是否对称，还是允许一侧更狠？第一刀要保证站在中段能稳定体验「增强→风眼平静→再增强」。

## Answer

### 采样

局部强度相对**台风中心**沿路径的水平有符号距离 `s` 采样；左右**对称**。尺度取本场路径水平长 `L`（随 spawn 起终点变化）。命令不暴露剖面参数。

### 内置分段（对 `|s|`）

| 区段 | `|s|` | 强度 |
| --- | --- | --- |
| 风眼 | `0 ~ 0.05 L` | **0** |
| 峰值（眼墙） | `0.05 L ~ 0.15 L` | **峰值等级**（平台） |
| 斜坡 | `0.15 L ~ 0.45 L` | 峰值 ↔ 0 **线性** |
| 更远 | `> 0.45 L` | **0**（仍可能在影响宽度内） |

验收参考：`L ≈ 128` 区块时，风眼约 6.4 区块宽，眼墙每侧约 12.8 区块；中段可稳定感到增强 → 眼平静 → 再增强。

### 过眼风向

- **自动反转：** 相对中心，前半侧主风向 = 路径水平方向，过风眼后 = **反向**。
- 迎风面、吹玩家、吹掉落物都读反转后的主风向。
- 若命令提供了主风向**手动覆盖**，则整场固定为覆盖值，**覆盖优先于**自动反转。
