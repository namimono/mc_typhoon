# 第一刀生成命令长什么样

Type: grilling
Status: resolved
Blocked by: 01, 02

## Question

验收依赖命令生成台风。第一刀命令的参数面是什么：必选/可选（起点、终点或方向、最高等级、名称、宽度……）？默认值怎么定才够测「靠近→增强→风眼→另一侧」整条体验？

## Answer

### 路径与风向

- **路径：** 只要**起点 + 终点**（方块坐标）；中心沿线段移动。不做「方向+长度」第二形态。
- **水平投影走路径**（Y 照收，几何以水平为主）。
- **主风向：** 默认 = 路径水平方向；**可选手动覆盖**。

### 参数面

| | 参数 | 默认 |
| --- | --- | --- |
| 必选 | 起点、终点 | — |
| 可选 | 峰值等级（1–6） | **6** |
| 可选 | 影响宽度（半宽） | **16 区块**；命令单位用**区块**（实现 ×16），对齐玩家视距心智 |
| 可选 | 过境时长 | **12000 tick（游戏内半天）**；移动速度 = 路径水平长 ÷ 时长 |
| 可选 | 名称 | `Typhoon-<短id>`；要「海燕」时再传 |
| 可选 | 主风向覆盖 | 无则路径向 |
| 不进命令 | 风眼宽度 / 强度剖面比例 | **内置**（弱→强→眼→强→弱） |

示意（非最终 Brigadier 字面量）：

```text
/typhoon spawn <from> <to> [peak] [widthChunks] [durationTicks] [name] [wind ...]
/typhoon clear
/typhoon list
```

### 子命令（第一刀）

- **`spawn`** — 生成一场台风（写入 SavedData，见第 02 票）
- **`clear`** — 清除当前维度全部台风（重测用）
- **`list`** — 列出进行中的 id / 名称 / 进度
- **不做：** 改参、转向、暂停

权限：约原版天气类（建议作弊 **2 级**）；本票不展开权限框架。

### 验收约定（文档，非命令参数）

- 测试路径水平长约 **64～128 区块**（1024～2048 格），玩家站中段附近稍偏一侧。
- 默认带宽盖住常见 12～16 视距；32 视距把 `widthChunks` 调到 32。
- 默认一场过境 ≈ 游戏内半天，能完整感受靠近→增强→风眼→另一侧→离开。
