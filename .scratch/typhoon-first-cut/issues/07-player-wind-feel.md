# 玩家受风体感阈值

Type: grilling
Status: resolved
Blocked by: 01

## Question

第一刀里，强度剖面各段对玩家分别造成什么：轻微偏移、逆风减速/顺风加速、无法冲刺、跳跃偏移、离地？阈值如何挂到「剖面强度」而不是再发明一套平行等级？单人下可接受的夸张程度？

## Answer

### 刻度

效果只读**局部强度**（与峰值等级、抗风等级同一套 1–6）；`floor` 成档后查表。风眼 / 带外 ≈ **0** → 玩家风力全关。不另造「玩家风级」。

### 挂载表（越高叠加越低档）

| 局部强度 | 玩家效果 |
| --- | --- |
| 0 | 无 |
| 1 | 水平轻微偏移 |
| 2–3 | + 逆风减速 / 顺风加速（3 比 2 更强）；约 ±20%～40% 水平移速体感量级 |
| 4 | + **无法正常冲刺**（可走，Sprint 废） |
| 5 | + **跳跃轨迹被吹偏** |
| 6 | + **力学地狱**：强抬升 + 沿主风向猛吹，难站稳/难落地；逆风几乎无效 |

### 夸张与「活不下来」

- 4–5 已经很难受；**6 不追求多数玩家能扛过去**。
- 6 的死亡率来自失控、摔落、吹进危险地形等，**风本身不直接扣血**。
- 刻意不做：永久无重力飘飞、创造模式同强度猛吹。

### 模式例外

**创造且可飞行，或旁观：玩家风力关闭**，不影响创造搭建 / 验收。
