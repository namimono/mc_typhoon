# 台风可玩第一刀

Status: ready-for-agent

## Problem Statement

玩家想在 Minecraft 里经历一场「真的在移动」的台风：它沿路径靠近、增强、进入风眼平静、另一侧再增强，水平风推动人与掉落物，迎风弱方块逐渐裂开并被吹走，影响带内自管下雨且风眼里停雨，并能从粒子与轻量 UI 感到风向与进度。当前模组几乎是空骨架，缺少可命令生成、可存档、可验收的第一刀玩法。

## Solution

提供单人优先的第一刀：用命令生成一场**台风**（起点→终点路径）；权威状态在服务端按世界 tick 推进**台风中心**；任意坐标可读**局部强度**与**主风向**（含过眼反转）；在**影响带**内推动玩家、做**迎风面**上的**风力破坏**（可见裂纹）、吹走掉落物并可撞击致伤；客户端叠加**台风雨**与风向粒子；Boss 栏与聊天展示名称与进度。自然生成、雷达、风味灾害解锁等不做。

## User Stories

1. As a 单人玩家, I want 用命令生成一场有名称的台风, so that 我能随时验收整条过境体验
2. As a 单人玩家, I want 指定路径起点与终点, so that 台风中心沿我选的路线移动
3. As a 单人玩家, I want 可选峰值等级（默认 6）, so that 我能测满档或较弱台风
4. As a 单人玩家, I want 可选影响宽度（默认半宽 16 区块）, so that 带宽盖住常见视距
5. As a 单人玩家, I want 可选过境时长（默认游戏内半天）, so that 一场台风不会一晃而过
6. As a 单人玩家, I want 可选名称（默认短 id 名）, so that 我能叫它「海燕」之类
7. As a 单人玩家, I want 可选覆盖主风向, so that 验收时不必改路径也能横风
8. As a 单人玩家, I want 默认主风向跟路径水平方向, so that 少一个必填参数
9. As a 单人玩家, I want `/typhoon clear` 清掉当前维度台风, so that 我能反复重测
10. As a 单人玩家, I want `/typhoon list` 列出进行中的台风, so that 我知道 id、名称与进度
11. As a 单人玩家, I want 台风状态随世界存档保存加载, so that 退出再进台风还在
12. As a 单人玩家, I want 台风中心按时长匀速走完路径, so that 过境时间可预期
13. As a 单人玩家, I want 站在路径中段感到弱→强→风眼→强→弱, so that 体验完整剖面
14. As a 单人玩家, I want 风眼里局部强度为 0, so that 雨停风弱、产生「结束了？」的错觉
15. As a 单人玩家, I want 过风眼后主风向自动反转, so that 另一侧眼墙体感正确
16. As a 单人玩家, I want 手动覆盖风向时整场不自动反转, so that 覆盖语义清晰
17. As a 单人玩家, I want 离开影响宽度后不受该台风影响, so that 世界其它地方正常
18. As a 单人玩家, I want 局部强度 1 时行走轻微偏移, so that 能感到轻风
19. As a 单人玩家, I want 局部强度 2–3 时逆风减速、顺风加速, so that 风向有意义
20. As a 单人玩家, I want 局部强度 4 时无法正常冲刺, so that 强风限制机动
21. As a 单人玩家, I want 局部强度 5 时跳跃被吹偏, so that 极强风更难控
22. As a 单人玩家, I want 局部强度 6 时陷入力学地狱（强抬升+猛吹）, so that 多数人难以在眼墙存活
23. As a 单人玩家, I want 风本身不直接扣血, so that 危险来自失控与环境而非无形伤害
24. As a 创造模式可飞行的玩家, I want 不受玩家风力, so that 我能搭验收场
25. As a 旁观者, I want 不受玩家风力, so that 观察不被掀翻
26. As a 单人玩家, I want 迎风弱方块出现挖掘式裂纹, so that 破坏过程看得见
27. As a 单人玩家, I want 破完后掉落物出现, so that 世界留下残骸
28. As a 单人玩家, I want 背风侧不优先被破, so that 加固迎风墙有意义
29. As a 单人玩家, I want 平地大体不被整片铲掉, so that 世界不会被犁成深渊
30. As a 单人玩家, I want 悬崖迎风侧可被剥蚀, so that 突出结构仍有风险
31. As a 单人玩家, I want 树叶/玻璃等比木石更早坏, so that 抗风等级体感合理
32. As a 单人玩家, I want 铁块比普通石更耐、钻石/下界合金块可在满档被毁, so that 顶级风仍有毁灭感
33. As a 单人玩家, I want 基岩与黑曜石族不被风力破坏, so that 世界锚点还在
34. As a 单人玩家, I want 破坏有渐裂节奏（不秒碎也不磨死）, so that 台风中能看见过程
35. As a 单人玩家, I want 强度不够时裂纹清除, so that 行为像原版松手停挖
36. As a 单人玩家, I want 掉落物被风吹走并轻度抬升, so that 有碎片乱飞的感觉
37. As a 单人玩家, I want 够快的掉落物撞到生物造成伤害, so that 满天残骸有威胁
38. As a 单人玩家, I want 撞击伤害随局部强度变强, so that 眼墙更危险
39. As a 创造可飞/旁观玩家, I want 不被掉落物撞击伤害, so that 搭建不受扰
40. As a 穿甲玩家, I want 撞击伤害吃原版护甲减免, so that 装备仍有价值
41. As a 单人玩家, I want 影响带内台风雨随局部强度表现, so that 台风不只是干风
42. As a 单人玩家, I want 风眼里台风雨停下, so that 平静段成立
43. As a 单人玩家, I want 台风雨不抢走原版全局 /weather, so that 原版天气命令仍独立
44. As a 单人玩家, I want 粒子表现风向, so that 不看 UI 也能感到风从哪来
45. As a 单人玩家, I want Boss 栏显示台风名与局部/峰值强度, so that 过境中有持续提示
46. As a 单人玩家, I want Boss 栏进度条表示路径进度, so that 知道台风走了多远
47. As a 单人玩家, I want spawn/list 在聊天给摘要, so that 命令反馈清楚
48. As a 模组开发者, I want 权威逻辑可在无完整客户端的情况下测台风场行为, so that 回归快且稳
49. As a 模组开发者, I want 远距离台风不依赖 Entity chunk tick, so that 中心走出玩家加载区仍推进
50. As a 单人玩家, I want 第一刀没有门乱开等风味解锁, so that 范围可控、尽快可玩

## Implementation Decisions

### 架构与接缝

- **主接缝：台风场（Typhoon field）**——深模块，承载一场/多场台风的生成、清除、列表、按 tick 推进、以及对坐标的采样与派生规则（局部强度、主风向、影响带、迎风判定、抗风解析、破坏进度步进、玩家风力档、掉落物目标速度与撞击伤害判定）。测试只打这一面。
- 服务端权威状态用 **SavedData**（类比原版 Raids）挂在维度数据存储；用 Fabric **世界 tick** 驱动台风场，不把台风权威状态做成 Entity，第一刀也不以 Attachment 作主方案。
- Minecraft 适配（命令、SavedData 读写、`destroyBlockProgress`/`destroyBlock`、玩家运动修改、掉落物施力、Boss 栏、客户端雨与粒子、同步包）放在接缝**外侧**；第一刀以手工/少量集成验收适配层。

### 领域与刻度

- 用语遵循根目录领域 glossary：台风、台风中心、路径、强度剖面、风眼、影响宽度、影响带、主风向、局部强度、峰值等级、抗风等级、迎风面、背风、台风雨、风力破坏。
- 局部强度、峰值等级、抗风等级共用 **1–6** 刻度；风眼/带外局部强度按 **0** 处理效果全关。

### 命令

- `/typhoon spawn|clear|list`；权限约作弊 2 级。
- spawn 必选起点、终点（方块坐标；路径用水平投影）；可选峰值（默认 6）、影响半宽（默认 **16 区块**，命令单位用区块）、过境时长（默认 **12000 tick**）、名称、主风向覆盖。
- 移动速度由路径水平长 ÷ 时长反推。风眼宽度与剖面比例**不进命令**（内置）。

### 强度剖面与风向

- 相对台风中心沿路径距离 `s` 采样；尺度 `L` = 路径水平长；**左右对称**。
- `|s|`：`0~0.05L` 风眼=0；`0.05L~0.15L` 眼墙=峰值；`0.15L~0.45L` 线性到 0；更远=0。
- 默认主风向=路径水平方向；过眼后**自动反转**；若命令覆盖主风向，整场固定，覆盖优先。

### 抗风

- 遵循 ADR：先跳过/免疫与 `typhoon:` 例外 tag，否则 `getDestroySpeed` 分箱到 1–6。
- 例外档：叶/玻璃=1，木=2，普通石=3，深板岩=4，铁系=5，钻石块与下界合金块=6。
- 免疫：基岩、barrier、黑曜石/哭泣黑曜石、强化深板岩、WITHER_IMMUNE、命令方块类；流体/空气/可替换不参与破坏。
- 分箱边界按已决议 hardness 区间；第一刀无单方块 override JSON。

### 风力破坏

- 仅迎风候选且局部强度 > 抗风；轴对齐同列水平遮挡；地面不特判（平地几乎不破）。
- 进度用服务端 destroyBlockProgress（负 id 池）+ destroyBlock 掉落；不必假玩家。
- 扫描：已加载 ∩ 影响带 ∩ 生存/冒险玩家约 ±32 水平 / ±16 垂直；约 64–128 判定/tick；并发裂纹约 16–32；带内无此类玩家则不扫破坏。
- 速率由超额=局部强度−抗风驱动（约 1→4–6s、2→2–3s、3+→~1s 破完一块）。
- 超额≤0 或风眼：**清除**进度（对齐原版松手）。

### 玩家风力

- 挂局部强度：1 轻偏；2–3 顺逆变速；4 禁冲刺；5 跳偏；6 力学地狱（风不直接扣血）。
- 创造且可飞行、或旁观：玩家风力关闭。

### 掉落物

- 水平推 + 随强度轻抬升；终端约 1→3、3→8、6→14 格/秒；约 0.5–1 秒加速到位。
- 施力范围与破坏类似玩家窗；约 32–64 个/tick 轮转；不改原版 despawn；保留 merge。
- 撞击：水平速率 ≥ **5 格/秒** 才致伤；底伤 2 ×（局部强度/3，夹约 0.5–2）；同实体对同生物冷却 20 tick；不分物品、忽略堆叠；撞后不消失；护甲吃原版减免；创造可飞/旁观免疫。不打建筑、不做独立碎片实体。

### 台风雨与展示

- 服务端同步台风几何/强度；客户端叠加雨粒子与音效；不修改全局 /weather；风眼 strength=0 停雨；湿润/作物逻辑不做。
- 风向以粒子为主。
- Boss 栏：标题含名称与局部/峰值；进度条=路径进度；同维度进行中显示，结束清除；多场只跟一场。
- 聊天：spawn 摘要；list 明细。

## Testing Decisions

- **好测试**：只断言台风场接缝的对外行为（采样值、步进后状态、判定结果、伤害是否触发与冷却），不断言私有结构、具体类名或 Minecraft 包发送细节。
- **主测模块**：台风场（含注入的方块探测替身：实心/抗风/硬度或 tag 结果）。
- **优先覆盖**：剖面分段与风眼 0、过眼风向反转与覆盖优先、影响带内外、抗风例外与分箱、迎风/背风、超额破坏进度与清进度、玩家风力档、掉落终端速度与 ≥5 格/秒伤害门槛及冷却。
- **现有 prior art**：仓库尚无业务测试；使用已配置的 JUnit 5 单测作为第一刀回归面。客户端雨/粒子/Boss 栏/命令注册以手工验收或日后薄集成测补充，不阻塞主接缝绿测。

## Out of Scope

- 天气雷达与科技线；自定义大信息面板/动作栏风向字
- 独立飞行碎片实体；碎片再破坏建筑/玻璃
- 按等级解锁的风味灾害（门乱开、专属屋顶演出等）
- 灾后统计结算界面
- 自然随机生成、复杂生命周期转向/突然消散
- 真实旋转/圆形风场；圆形「风圈」模型
- 多人联机权威同步专项（单人优先）
- 台风雨导致的方块湿润/作物逻辑
- 第一刀单方块抗风 override 表
