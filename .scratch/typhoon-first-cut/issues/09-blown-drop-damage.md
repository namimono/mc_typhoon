# 被风吹的掉落物撞击伤害怎么算

Type: grilling
Status: resolved
Blocked by: 01, 07

## Question

第一刀里，风力破坏产生的掉落物在被主风向吹走的过程中，若撞到生物（含玩家）要造成伤害。伤害阈值如何定：与掉落物速度、局部强度、物品种类/质量是否挂钩？对谁生效（玩家/怪物/盔甲减免）？创造玩家是否受伤？是否设冷却以免同一堆掉落物每 tick 碾伤？不把「独立飞行碎片实体」或「碎片打建筑」做进来的前提下，最小可玩规则是什么？

## Answer

### 最小可玩模型（A+C）

1. 掉落物须在影响带内、且被判定为**被风驱动中**（水平速度超过门槛）才可能致伤。  
2. **基础伤害 2（1 心）**/次。  
3. 再乘局部强度倍率：**×(局部强度 / 3)**，结果夹在约 **0.5～2.0**。  
   - 示意：强度 3 → 约 2 点；强度 6 → 约 4 点；强度 1 → 约 1 点（若仍过速）。  
4. **不**按物品种类分表；**忽略**堆叠数量。  
5. **不做**独立碎片实体、**不**用掉落物打建筑/再碎玻璃。

### 冷却与命中后

- 同一**掉落物实体 → 同一生物**冷却 **20 tick（1 秒）**，防止每 tick 碾伤。  
- 撞人后掉落物**不消失**，可继续飞、冷却后可再撞（含别的目标）。

### 对谁生效

| 目标 | 第一刀 |
| --- | --- |
| 生存 / 冒险玩家 | 会受伤 |
| 其他生物（怪物/动物等） | 会受伤 |
| 创造且可飞行，或旁观 | **免疫**（对齐第 07 票） |
| 护甲 | **吃原版护甲减免**（通用可护甲伤害来源） |

### 速度门槛（占位）

具体水平速率阈值随「掉落物被风吹走」手感一起定；见新票 [掉落物被风吹走的手感与速度](10-blown-drop-motion.md)。本票只要求：未达「明显被风拖着飞」的下限则**不结算**撞击伤害。
