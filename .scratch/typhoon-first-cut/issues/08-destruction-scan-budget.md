# 破坏速率与扫描预算

Type: grilling
Status: resolved
Blocked by: 01, 03

## Question

迎风面破坏要看见挖掘式进度，又不能全图扫方块。第一刀的扫描范围、每 tick 预算、破坏速率如何随强度变化？简化迎风判定（朝向 + 同列遮挡）的规则是否足够，还是要再砍一刀？

## Answer

### 迎风判定（第一刀用简化版，不再砍）

- 对象是**轴对齐方块格**（楼梯/半砖等按所占格），非法线、不射斜线。
- 主风向投到水平轴；看该格朝风一侧是否被**同列更迎风的实心格**挡住。
- 挡住 → **背风**，本 tick 不破；未挡住 → **迎风面**候选。
- 仅 `局部强度 > 抗风等级` 的迎风候选进入破坏进度（裂纹 API 见第 03 票）。

### 地面（不特判）

吃现有迎风规则即可：

- 大片平地互相水平遮挡 → **几乎不破**。
- 悬崖/缺口朝风 → 可被一排排剥蚀。
- 屋内地板中间多互挡 → 基本安全；门洞等边缘可能短时暴露。
- **顶面不算迎风面**（主风向水平）。第一刀不做「慢速削地表」特规。

### 扫描范围

每 tick 只考虑：

**已加载区块 ∩ 影响带 ∩ 每个生存/冒险玩家周围盒子**

- 水平约 **±32 格**，垂直约 **±16 格**（与裂纹可见距离同量级）。
- 影响带内**没有**这类玩家 → **不跑破坏扫描**（台风状态照常 tick）。

### 每 tick 预算

| 项 | 第一刀 |
| --- | --- |
| 读块 + 迎风/抗风判定 | 全维度合计约 **64～128**/tick，滑动光标轮转扫完窗口 |
| 同时播裂纹的方块 | 约 **16～32**（负 id 池）；满则优先维护已有进度 |

### 破坏速率

\[
\text{超额} = \text{局部强度} - \text{抗风等级}
\]

| 超额 | 破完一块约 |
| --- | --- |
| ≤ 0 | 不破 |
| 1 | **~4–6 秒** |
| 2 | **~2–3 秒** |
| 3+ | **~1 秒**量级 |

目标：台风里能看出**逐渐裂开**，不秒碎、不磨死。不按原版 hardness 再二次缩放（材料差已在抗风等级）。进度按超额累加至 stage 9 再 `destroyBlock`。

### 强度掉下去时

**清除该格破坏进度并释放 breakerId**（对齐原版手挖松手清裂纹）。风眼或超额≤0 同此；强度再够则从头破。不冻结、不回退动画。
