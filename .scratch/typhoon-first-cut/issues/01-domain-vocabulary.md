# 第一刀台风领域用语

Type: grilling
Status: resolved

## Question

为本模组第一刀钉死一套领域用语（写入 `CONTEXT.md`）：台风实体、强度剖面、风眼、风带/影响宽度、主风向、抗风等级、迎风面等分别叫什么、边界在哪、刻意避免哪些近义词？

## Answer

第一刀领域用语已写入仓库根目录 [`CONTEXT.md`](../../../CONTEXT.md)。会话中逐项确认，结论如下。

### 核心

| 规范名 | 要点 |
| --- | --- |
| **台风** | 一场区域天气事件；不作「实体/实例」核心名 |
| **台风中心** | 路径上当前参考点；≠ 风眼 |
| **路径** | 中心移动所沿的线 |
| **强度剖面** | 沿路径 1D 强度曲线（弱→强→风眼→强→弱） |
| **风眼** | 剖面上的平静**段**（可有宽度） |
| **影响宽度** | 路径左右半宽；不用「风圈/半径」 |
| **主风向** | 水平主导风向；第一刀无旋转风场 |
| **局部强度** | 坐标处剖面采样；效果都读它 |
| **峰值等级** | 本场上限档（约 1–6）；命令/展示上限 |
| **抗风等级** | 方块阈值档；与强度同刻度比较 |
| **影响带** | 宽度内、可受影响的水平区域 |
| **迎风面** | 判定结果（朝向+遮挡），非方块类型 |
| **背风** | 被挡、不优先破坏的一侧 |
| **台风雨** | 影响带内叠加降水；≠ 原版 `/weather` |
| **风力破坏** | 超抗风后的挖掘式破坏过程 |

### 刻意拆开

- **局部强度** / **峰值等级** / **抗风等级** 三词分用，禁止「等级」一词打天下。
- **台风中心 ≠ 风眼**；**影响宽度 / 影响带** 不用圆形「风圈」隐喻。

### 不进 glossary（第一刀）

雷达、飞行碎片、灾后统计、自然生成等仍在 map Out of scope；展示名「海燕」、掉落吹走手感等仍在 Not yet specified。
