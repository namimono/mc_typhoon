# 掉落物被风吹走的手感与速度

Type: grilling
Status: resolved
Blocked by: 01, 07, 09

## Question

风力破坏产生的掉落物如何被主风向推动：加速度/终端速度、与局部强度的关系、是否贴地滑行还是可抬升、寿命与despawn、以及「被风驱动中」的水平速度门槛（供第 09 票撞击伤害使用）？第一刀要夸张到什么程度才既看得见满天乱飞，又不把物品实体 tick 打爆？

## Answer

### 运动模型

- **水平推 + 随局部强度轻度抬升**（不是纯贴地滑，也不是强力乱舞抛射）。
- 重力仍在；不是永久悬浮。
- **不分物品质量**（与第 09 票一致）。

### 速度（水平，沿主风向；随局部强度插值）

| 局部强度 | 水平终端速度（约） | 抬升 |
| --- | --- | --- |
| 1 | **~3 格/秒** | 很弱，几乎贴地 |
| 3 | **~8 格/秒** | 明显飘起一点 |
| 6 | **~14 格/秒** | 碎块能腾空掠过 |

- 加速度：约 **0.5～1 秒**内接近终端速度。
- 离开影响带或风力停止后：不再施力，按**原版**阻力减速。

### 撞击伤害门槛（供第 09 票）

水平速率 **≥ 5 格/秒** 才视为「被风驱动中」，可结算掉落物撞击伤害。

### 范围、预算与寿命

| 项 | 第一刀 |
| --- | --- |
| 谁被吹 | 影响带 ∩ 已加载 ∩ **玩家附近**（约水平 ±32 格，与破坏扫描同量级） |
| 每 tick 预算 | 全维度约 **32～64** 个掉落物施加风力（轮转） |
| 寿命 | **不改原版 despawn**；风不额外销毁物品 |
| 合并 | 保持原版 item merge |
