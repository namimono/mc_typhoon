# 台风命名与展示放哪

Type: grilling
Status: resolved
Blocked by: 01, 06

## Question

第一刀里台风名称（命令可选，默认 `Typhoon-<短id>`）以及「位置/等级/方向」类信息如何展示才够用：仅聊天反馈、boss栏、动作栏、还是简单状态画面？单人优先下最小信息面是什么，哪些留到雷达（已 Out of scope）之后？

## Answer

### 最小信息面

**聊天 + Boss 栏。** 第一刀不做动作栏风向字、不做自定义状态 HUD、不做雷达/信息面板。

风向仍靠**粒子**（地图已定）。

### Boss 栏

| 元素 | 内容 |
| --- | --- |
| 标题 | `台风「名称」 · 局部强度 n/峰值`（脚下局部强度采样；名称来自命令或默认 `Typhoon-<短id>`） |
| 进度条 | **路径进度**：台风中心从起点走到终点的比例（不是血量） |
| 可见范围 | 同维度、台风进行中；结束后清除 |
| 多场 | 第一刀条只跟踪**一场**（最近或优先一场）；详情靠 `list` |

颜色随强度变化可选；第一刀固定一色也可。

### 聊天

- **`spawn`：** 回报名称与起终点等摘要  
- **`list`：** id / 名称 / 路径进度等明细  

### 明确留给日后（含雷达）

相对方位「东南 3200 格」、风速 m/s 面板、地图式追踪 UI —— **不做进第一刀**。
