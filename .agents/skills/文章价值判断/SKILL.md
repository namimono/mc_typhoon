# 文章价值判断

先判断文章有没有真信息，再判断它是不是在包装、带节奏或导流。目标是给出清晰结论，不是机械摘要。

## 使用流程

1. 先确认你实际拿到了什么。

- 如果拿到了全文，先读完再判断。
- 如果只有标题、片段、截图、摘要或受限页面，必须明确说明判断范围，只能对已看到的内容下结论。
- 不要把评论区、平台按钮、相关推荐、排版噪音当成正文内容。

2. 先用一句话说清这篇文章到底在讲什么。

- 它的主题是什么。
- 它最想让读者相信的 2 到 5 个核心观点是什么。
- 它主要是在做哪件事：
  - 报道事实
  - 解释方法
  - 解读趋势
  - 输出观点
  - 推销产品、服务、课程、社群或某种叙事

3. 判断信息价值，不要只看文风。

重点看这些：

- 有没有新事实、新数据、新案例、新方法、新观察。
- 有没有足够具体的细节，能让读者读完后获得可执行的认知或动作。
- 有没有来源、论文、报告、时间、机构、样本、对比对象、限制条件。
- 有没有边界、反例、失败条件、成本、风险、适用场景。
- 去掉形容词和情绪词之后，还剩下多少真正有用的信息。

高价值信号：

- 有明确来源和可核查信息
- 有数字且交代背景
- 有具体案例和复现路径
- 有限制条件和适用边界
- 有方法步骤，不只是观点口号
- 愿意承认不确定性

低价值信号：

- 大量“颠覆”“重构”“时代变了”“普通人机会来了”
- 反复讲正确的废话，但没有新增信息
- 把常识重新命名后包装成新概念
- 开头很炸，中间很空，结尾很鸡血
- 读完只能得到“要重视”“要转型”“别掉队”

4. 判断是不是广告、软广或营销包装。

重点识别这些模式：

- 制造焦虑、制造落后恐惧、制造身份压力
- 频繁强化某个品牌、平台、公司、创始人、课程、训练营、咨询服务、社群
- 案例和证据只服务于一个商业结论，没有平衡视角
- 结尾导流：关注公众号、加微信、进群、预约咨询、购买课程、领取资料、下载产品、试用服务
- 明显“种草”结构：先讲趋势，再讲痛点，再给唯一解法
- 用“大厂背书”“名校背书”“行业黑话”抬高可信度，但正文细节不足

结论口径可用：

- `不是广告`：主要在传递信息，没有明显转化目标
- `轻度营销`：有信息，但也在刻意塑造对某产品、公司或观点的好感
- `营销偏重`：文章结构明显在说服和引导，不只是传递信息
- `纯软广/废文`：独立信息价值很低，主要目的就是吸引、转化、带货、导流或刷存在感

5. 把“有用部分”和“包装部分”拆开说。

- 如果文章有真实信息，就指出具体哪几段有用。
- 如果文章存在夸张、偷换概念、结论过度外推，也要明确指出。
- 不要把“有一点信息”和“值得深读”混为一谈。

## 输出格式

默认按下面格式回答：

### 结论

从下面几类里选一个最贴切的：

- `值得读`
- `可略读`
- `信息价值较低`
- `营销偏重`
- `纯软广/废文`

### 原因

至少说明：

- 这篇文章真正的主题是什么
- 它到底提供了哪些有用信息
- 它缺了什么，或者夸张了什么
- 有没有明显营销、导流、包装、带节奏成分

### 真正有用的部分

- 提炼 1 到 3 条最值得保留的信息

### 可疑信号

- 点出最明显的标题党、营销、证据不足、逻辑跳跃、过度包装问题

## 回答风格

- 优先给判断，再给解释。
- 不要把回答写成读书笔记。
- 不要泛泛而谈，要引用文章里的具体现象支撑判断。
- 如果文章是技术解读、论文解读、行业分析，要分清：
  - 原始来源本身有没有价值
  - 这篇二次传播文章有没有过度放大
- 如果证据不足，就直接说“现有内容不足以确认”，不要硬下结论。

## 中文内容生态下的快速判断法

- 标题极强，正文极弱，通常要降级判断。
- 开头先制造焦虑，中间讲趋势，结尾导流，通常是营销文高发结构。
- 大量“普通人机会”“认知差”“错过就晚了”“一夜提升效率”，通常要警惕。
- 高频使用“清华/斯坦福/大厂/顶会/专家”背书，但没有展开实验边界，通常是借权威包装。
- 如果读完能明确知道“是什么、为什么、适用哪里、不适用哪里、怎么做”，通常价值不低。
- 如果读完只留下情绪，没有留下新事实和新方法，通常不值得读。

## 典型触发语

- “分析这篇文章值不值得读”
- “看看是不是广告”
- “是不是营销号内容”
- “帮我判断有没有信息密度”
- “提炼这篇文章真正有用的部分”
- “这篇公众号是不是在带节奏”
- “判断这篇文章是干货还是包装”
